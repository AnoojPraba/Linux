# 43_GraphAlgorithms

Graph algorithms in modern C++: BFS, DFS, topological sort, shortest paths, spanning trees and union-find.

## Files
- `01_graphAlgorithms.cpp` - BFS shortest path, DFS topological sort with colour-based cycle detection, Dijkstra with priority_queue.
- `02_unionFindKruskal.cpp` - Disjoint sets (union by size + path halving) and Kruskal's minimum spanning tree.
- `03_graphRepresentations.cpp` - Graph representations and conversions in C++: edge list, adjacency matrix and adjacency list, degrees, density, transpose and weighted edges.
- `04_dfsApplications.cpp` - DFS applications: connected components, cycle detection (undirected and directed), entry/exit times and edge classification, path finding.
- `05_bfsApplications.cpp` - BFS applications: shortest path with reconstruction, grid maze, bipartite test, multi-source BFS and level-order grouping.
- `06_floodFillAndIslands.cpp` - Grid graphs: flood fill, number of islands (DFS and union-find), largest island and surrounded regions.
- `07_wordLadderImplicitGraph.cpp` - BFS on an implicit graph: word ladder where neighbours are generated by changing one letter, with path reconstruction.
- `08_cloneGraphAndUnionFindProblems.cpp` - Common graph interview problems: clone a graph, redundant connection and accounts merging with union-find, and finding the town judge by degrees.
- `09_topologicalSortAndCourses.cpp` - Topological sorting three ways: Kahn (BFS), DFS finishing order, and the lexicographically smallest order; with cycle detection and course scheduling.
- `10_dijkstraPathsAndVariants.cpp` - Dijkstra with a priority_queue: distances, path reconstruction, early exit, counting shortest paths and a bottleneck (minimax) path.
- `11_shortestPathVariants.cpp` - Shortest-path problem variants: at most K stops (layered Bellman-Ford), maximum-probability path, network delay time and cheapest path with fuel.
- `12_zeroOneBfsAndSpfa.cpp` - 0-1 BFS with a deque (weights 0 or 1) and SPFA, the queue-based Bellman-Ford with negative-cycle detection.
- `13_bellmanFordNegativeCycle.cpp` - Bellman-Ford: shortest paths with negative edges, negative-cycle detection and printing the cycle itself, plus shortest paths with at most k edges.
- `14_aStarGrid.cpp` - A* search on a grid: Manhattan heuristic, path reconstruction and a comparison of nodes expanded with Dijkstra and BFS.
- `15_floydWarshallPathsAndClosure.cpp` - Floyd-Warshall all-pairs shortest paths with path reconstruction, negative-cycle detection and transitive closure (Warshall).
- `16_primAndBoruvka.cpp` - Minimum spanning trees beyond Kruskal: Prim with a priority_queue and Boruvka (cheapest edge of every component per round).
- `17_stronglyConnectedComponents.cpp` - Strongly connected components with Kosaraju and Tarjan, and the condensation DAG.
- `18_articulationPointsAndBridges.cpp` - Cut vertices and bridges with Tarjan's discovery-time/low-link DFS, handling the root and parallel edges.
- `19_lcaBinaryLiftingAndDiameter.cpp` - Tree algorithms: LCA with binary lifting, distance between nodes, kth ancestor and the tree diameter by two sweeps.
- `20_dagLongestPathAndCriticalPath.cpp` - DP on a DAG: longest path, earliest start times and the critical path of a project schedule, plus counting paths.
- `21_girthAndShortestCycle.cpp` - Shortest cycle (girth) of an undirected graph by BFS from every vertex, and shortest cycle through a given edge.
- `22_johnsonAllPairs.cpp` - Johnson's algorithm: all-pairs shortest paths on a sparse graph with negative edges via Bellman-Ford potentials and Dijkstra from every vertex.
- `23_eulerianPathHierholzer.cpp` - Eulerian circuits and paths with Hierholzer's algorithm (undirected and directed) and the degree conditions for existence.
- `24_bipartiteMatching.cpp` - Maximum bipartite matching with Kuhn's augmenting paths and Hopcroft-Karp (BFS layers + DFS), with Konig's vertex cover.
- `25_maxFlowEdmondsKarp.cpp` - Maximum flow with Edmonds-Karp (BFS augmenting paths on the residual graph), the min cut and edge-disjoint paths.
- `26_maxFlowDinic.cpp` - Dinic's algorithm: BFS level graph, blocking flow by DFS with current-arc pointers, and a bipartite matching solved as a flow.
- `27_minCostMaxFlow.cpp` - Minimum-cost maximum flow with successive shortest paths (SPFA on the residual graph): assignment and transport problems.
- `28_twoSatWithScc.cpp` - 2-SAT with strongly connected components: build the implication graph, test satisfiability and produce an assignment.
- `29_graphColoringAndHamiltonian.cpp` - NP-hard graph problems by backtracking: m-colouring, Hamiltonian cycle and maximum independent set, with a greedy colouring heuristic.
- `30_tspBitmaskDp.cpp` - Travelling salesman by Held-Karp bitmask DP (O(2^n n^2)) with tour reconstruction, compared with brute force over permutations.
- `NOTES.md` - concise interview-focused notes for this topic

## Build and run
- Single file: `g++ -std=c++20 -Wall -Wextra -pthread 01_graphAlgorithms.cpp -o /tmp/x && /tmp/x` (swap in any other file listed above).
- `make` from `..` (the parent code/ dir) builds everything into `Cpp/code/bin/43_GraphAlgorithms/` (git-ignored).

## Key concepts / interview angles
- **Graphs:** adjacency list O(V+E) memory. **BFS** (queue) = shortest path in unweighted graphs, mark when queued. **DFS colours** white/grey/black: edge to grey = cycle; reverse finishing order = topological order. **Dijkstra**: non-negative weights, min-heap, push duplicates and skip stale entries, O((V+E) log V); negative weights -> Bellman-Ford.
- **Union-find:** union by size + path compression -> amortized O(alpha(n)). **Kruskal:** sort edges, take an edge if its ends are in different sets; MST of V-1 edges (fewer = disconnected). Prim is the dense-graph alternative.

## Gotchas
- Pushing an INF distance and adding a weight to it overflows - skip unreached vertices.
