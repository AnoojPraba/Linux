# GraphAlgorithms

- **Graphs:** adjacency list O(V+E) memory. **BFS** (queue) = shortest path in unweighted graphs, mark when queued. **DFS colours** white/grey/black: edge to grey = cycle; reverse finishing order = topological order. **Dijkstra**: non-negative weights, min-heap, push duplicates and skip stale entries, O((V+E) log V); negative weights -> Bellman-Ford.
- **Union-find:** union by size + path compression -> amortized O(alpha(n)). **Kruskal:** sort edges, take an edge if its ends are in different sets; MST of V-1 edges (fewer = disconnected). Prim is the dense-graph alternative.

## More algorithms in this folder
- **Representations:** edge list (Kruskal, Bellman-Ford), adjacency matrix (O(1) edge test, O(V^2) space, dense graphs, Floyd-Warshall), adjacency list (O(V+E) space, fast neighbour iteration, sparse graphs); weighted lists store `(to, weight)`. Conversions are O(V^2) or O(V+E); transpose reverses every edge.
- **DFS:** components (label by DFS), cycle detection (undirected: visited non-parent neighbour; directed: back edge to a grey vertex), entry/exit times classify edges (tree/back/forward/cross), path finding by backtracking, topological order by finishing time. Recursion depth = V in the worst case - use an explicit stack for large graphs.
- **BFS:** shortest paths in unweighted graphs (parent array), grid/maze, bipartite check (2-colour), multi-source BFS (push all sources first), level-by-level processing (snapshot `q.size()`), 0-1 BFS for 0/1 weights. Mark visited when pushing, not popping.
- **Flood fill/islands:** DFS/BFS or union-find (best when land is added incrementally); surrounded regions = flood from the border; 4- vs 8-connectivity.
- **Implicit graphs:** word ladder, puzzle states, knight moves: neighbours generated on the fly, `parent` map doubles as visited, BFS = fewest moves; bidirectional BFS halves the explored depth.
- **Topological sort:** Kahn (queue of in-degree 0; fewer than V outputs = cycle; min-heap = lexicographically smallest) or reverse DFS finishing order; course schedule = is the graph a DAG.
- **Dijkstra:** `priority_queue` of `(dist, v)` with `greater<>`, skip stale entries, O((V+E) log V), non-negative weights; count shortest paths by carrying `ways`; bottleneck (minimax) path = Dijkstra with `max` instead of `+`; parents rebuild the path.
- **0-1 BFS** (deque, O(V+E)) and **SPFA** (Bellman-Ford with a queue, average fast, worst O(VE), relaxation count > V = negative cycle). **Bellman-Ford:** V-1 passes, V-th pass relaxation proves a negative cycle; step back V times along parents to land on it; at most k edges = relax from a copy per round.

- **A\\*:** `f = g + h` with an admissible heuristic (never overestimates; Manhattan distance on a 4-connected grid); consistent `h` guarantees no re-expansion; with `h = 0` it is Dijkstra; fewer nodes expanded in practice. Reconstruct the path with parent pointers.
- **Floyd-Warshall:** `d[i][j] = min(d[i][j], d[i][k] + d[k][j])` with `k` as the OUTER loop; O(V^3); a negative `d[i][i]` signals a negative cycle; keep `next[i][j]` to rebuild paths; the same loop with `or`/`and` is the transitive closure.
- **Prim vs Boruvka vs Kruskal:** Prim grows one tree (heap, lazy deletion) O(E log V); Boruvka merges every component's cheapest edge each round (O(log V) rounds, parallel friendly); Kruskal sorts edges + union-find. Same weight for a unique MST.
- **Johnson:** virtual source + Bellman-Ford for potentials `h`, reweight `w' = w + h[u] - h[v] >= 0`, Dijkstra from each vertex, restore `d - h[s] + h[t]`; O(V E log V) for sparse graphs with negative edges.
- **SCC:** Kosaraju (finish order, then DFS on the transpose in decreasing order) or Tarjan (index/low-link + stack, pop at `low == index`); O(V+E); the condensation is a DAG; Tarjan numbers components in reverse topological order. Used for 2-SAT, deadlock groups, dependency cycles.
- **Cut vertices and bridges:** DFS with `disc`/`low`; bridge `low[v] > disc[u]`; cut vertex `low[v] >= disc[u]` (non-root) or root with 2+ children; track the parent EDGE id (not vertex) to survive parallel edges.
- **Trees:** LCA by binary lifting (`up[k][v]`, lift to equal depth, jump while ancestors differ), distance = `d[a] + d[b] - 2 d[lca]`, k-th ancestor by bits of k, diameter by two sweeps (farthest from anywhere, then from that node).
- **DAG DP:** process in topological order; earliest start = max over predecessors of (start + duration); the argmax chain is the **critical path**; counting paths and longest path use the same order. **Girth:** BFS from every vertex, non-tree edge gives `dist[u] + dist[v] + 1`.

- **Eulerian path/circuit** (every edge once): undirected - all degrees even (circuit) or exactly two odd (path from an odd vertex); directed - in = out everywhere (circuit) or one +1/-1 pair; edges must be connected. **Hierholzer** O(E): walk unused edges with a stack, emit a vertex when stuck, reverse. Hamiltonian (every vertex once) is NP-complete.
- **Bipartite matching:** Kuhn's augmenting paths O(V E); **Hopcroft-Karp** (BFS layers + DFS) O(E sqrt V); König: max matching = min vertex cover, max independent set = V - matching; equivalent to max flow source -> left -> right -> sink.
- **Max flow:** residual graph with reverse edges (so choices can be undone); **Edmonds-Karp** (BFS shortest augmenting path) O(V E^2); **Dinic** (level graph + blocking flow with current-arc pointers) O(V^2 E), O(E sqrt V) for unit networks. Max-flow = min-cut; the set reachable from the source in the final residual graph is the source side of a minimum cut. Unit capacities give edge-disjoint paths.
- **Min-cost max-flow:** successive shortest paths (SPFA/Bellman-Ford because reverse edges carry negative cost; Dijkstra with potentials is faster); solves assignment and transportation problems.
- **2-SAT:** clause (a or b) = implications NOT a -> b and NOT b -> a; satisfiable iff no variable shares an SCC with its negation; assign by component order; linear time (3-SAT is NP-complete).
- **NP-hard graph problems:** m-colouring and Hamiltonian cycle by backtracking, greedy colouring (<= max degree + 1 colours), maximum independent set by subsets; **Held-Karp** TSP O(2^n n^2) vs O(n!) brute force - fine up to n ~ 20.
- **Interview staples:** clone a graph (map old -> new doubles as visited), redundant connection (the edge whose ends are already united), accounts merge (union-find over shared emails), town judge (in-degree n-1, out-degree 0).
- **Shortest-path variants:** at most K stops = K+1 rounds of Bellman-Ford relaxing from a copy; max probability = Dijkstra with a max-heap and products; network delay = max of Dijkstra distances; bottleneck/minimax = Dijkstra with `max`; count paths by carrying ways.
